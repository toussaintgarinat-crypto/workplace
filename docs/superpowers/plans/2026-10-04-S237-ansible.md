# S237 — Plan d'implémentation

**Objectif :** provisionner Debian/Docker et déployer Workplace à un SHA explicite, puis prouver la reconstruction sur une VM distincte.

**Architecture :** Ansible orchestre des rôles séparés ; un catalogue décrit les projets Compose réels ; une garde vérifie la cible avant toute mutation. Les données persistantes vivent hors des releases ; un registre privé lie révision, configurations et déploiements.

**Contraintes globales :** aucune mutation de production ; Debian 13 ; secrets hors Git et sorties ; builds séquentiels ; RTO 28 800 secondes ; reprise simultanée du périmètre déclaré ; pas de notifications externes ; pas de prune global. Conception validée par l'utilisateur le 4 octobre 2026.
